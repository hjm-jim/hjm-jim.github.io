## 项目四：智审宝 —— AI帮你审，Chat带你报

![智审宝获奖证书](/images/proj4.jpg)

> 🏆 该项目获得某大型 B 端企业 AI Coding 大赛 **第二名**。
### 项目链接

- 📄 产品文档+demo视频：[飞书 Wiki](https://tcn2nyif8o7g.feishu.cn/wiki/BxnAwBsi5iGPF4kZzaOcHwgCn9b)
### 背景与痛点

高校师生在科研报销中面临三大困境：**流程信息获取难**（不同项目类型对应不同报销地点与审批路径，制度文件分散难以自查）、**财务人员重复解答**（同类问题每天被反复询问，大量时间消耗在标准问答上）、**材料问题反馈滞后**（提交后需数天乃至跨周才能完成审阅，一旦发现缺漏需来回沟通）。

调研阶段访谈了研究生、行政人员、导师、财务人员等多类角色，并回收 20 份真实问卷。核心发现：报销端用户不知道流程细节，频繁询问带来高摩擦成本；材料预审与流程清晰度是最痛的环节。

### 方案

一句话描述产品链路：**智能咨询 → 高效填报 → AI 预审 → 流程驱动 → 人工决策**。

#### 产品功能架构

- **报销端（Chat + 填报双通道）**：报销人通过 Chat 对话获取流程指引、填报链接和进度查询；在简道云表单中完成填报，票据 OCR 自动识别填表，字段约束即时校验，材料问题当场打回。
- **审批端（AI 预审 + 人工 Approve）**：学生提交报销后，后台 Agent 自动核查材料合规性，生成结构化预审报告（含准确度判定、风险等级、政策依据、修正建议），审批人员基于报告做最终决策。

#### 技术路线

- Chat 与预审节点使用 **Dify** 搭建工作流，实现分类器归类、会话变量上下文记忆、RAG 精确匹配报销条款。
- 简道云承载表单、流程引擎与数据存储，通过 Webhook 触发预审 Agent。
- 报销端适配手机/电脑双端；审批端聚焦浏览器布局，确保审慎决策体验。

#### 核心模块效果

| 模块 | 能力 |
|---|---|
| 报销规则匹配 | 对话式交互，AI 自动识别项目类型 → 匹配报销地点、流程、材料清单，用户可收藏结果复用 |
| 票据自动识别 | 拍照上传即自动填表（发票代码、日期、金额），合规校验当场提示，多票据批量处理 |
| 材料预审 | AI 生成预审报告卡片：完整性判定 + 风险等级 + 政策依据链接 + 修正建议路径 |
| 进度追踪 | Chat 端一句话查询工单进度，时间轴可视化展示，退回原因与补充材料清单直接呈现 |

### 成果

- 获某大型 B 端企业 AI Coding 大赛 **第二名**。
- 产品文档涵盖场景调研、需求分析、产品设计、运营方案全链路，具备完整落地思路。
