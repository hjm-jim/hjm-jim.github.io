# hjm-jim.github.io

Jingming Hu's personal academic homepage.

## 编辑指南

所有内容在 `index.md` 中编辑，分为三个板块：

- **个人信息** — 个人陈述 + 项目缩略图及链接
- **项目详情** — 每个项目的详细介绍
- **博文** — 博客文章的超链接列表

作者信息和社交链接在 `_config.yml` 的 `author` 字段中配置。

## 本地预览

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

访问 `http://localhost:4000`
